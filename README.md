# IkivCraft Resource Pack

Pack de ressources officiel du serveur IkivCraft.

## Version actuelle
- Minecraft Java Edition 1.21.4
- Resource pack format: 46

## Structure
- `pack/` : sources du resource pack
- `releases/IkivCraftPack.zip` : fichier à utiliser dans `server.properties`

Le ZIP final doit avoir `pack.mcmeta` directement à sa racine.
